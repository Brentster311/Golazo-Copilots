# GCP-0079 Planner Notes

## Direction

Planner should be an opt-in initial role for the first Complete-profile work item, offered before creation. This preserves Planner's pre-story purpose and removes the current requirement to complete POA artifacts before moving backward.

## Product Boundaries

- Human choice, not automatic request classification.
- First persisted work-item state only.
- POA remains the default and the only initial role for Express and Spike.
- No state-schema migration.

## POA Handoff

The existing User Story is the correct single delivery slice. Acceptance should verify both offer guidance and tool-level enforcement.
