## User Story

**As a** developer using Golazo Copilot V2,  
**I want** visual workflow tracking in VS Code and Visual Studio,  
**So that** I can see workflow status at a glance without reading markdown files.

## Background

Golazo V1 is invisible to the IDE — it exists only in:
- Copilot chat responses
- Markdown files on disk

Developers must manually check:
- What role am I in?
- What DoR/DoD items are complete?
- What artifacts exist?

## Scope

## Technical Notes

### VS Code Extension
- TypeScript
- `vscode.window.createStatusBarItem()` for status bar
- `vscode.window.createWebviewPanel()` for sidebar
- Spawns/connects to Golazo Agent

### Visual Studio Extension
- C# / .NET
- `Microsoft.VisualStudio.Shell.Interop` for tool windows
- WebView2 for hosting React UI
- Spawns/connects to Golazo Agent

### Shared WebView
- React + TypeScript
- Vite for building
- Single build output used by both extensions
