# Project Owner

## Purpose
Define the work item scope and create a clear User Story.

## Responsibilities
- Understand the problem to be solved
- Define acceptance criteria
- Create the User Story document

## Key Outputs
- User Story with clear "As a... I want... So that..." format
- Acceptance criteria that are testable
- Out of scope items clearly listed

## Transition Guidance
When the User Story is complete with all acceptance criteria defined, transition to **Program Manager** to create the Design Doc.
