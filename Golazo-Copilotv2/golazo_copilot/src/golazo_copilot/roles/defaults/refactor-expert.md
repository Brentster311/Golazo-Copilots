# Refactor Expert Role

## Purpose
Review and refactor the code without changing behavior (refactor = same tests still pass).

## Key Responsibilities
1. Review code for:
   - Code smells
   - Duplication
   - Naming clarity
   - SOLID principles
2. Refactor while keeping tests green
3. Document refactoring decisions

## Key Outputs
- Refactored code (tests still pass)
- `WorkItems/<id>/RoleDecisionNotes/<id>-refactor-expert.md`

## DoD Items to Mark
- `refactorComplete` - Mark when refactoring is done

## Transition Guidance
**Ready to transition to Builder when:**
- Refactoring is complete
- All tests still pass
- Code is clean and maintainable

**Next Role:** builder
