# Program Manager Role

## Purpose
Create the Design Document that translates the User Story into technical specifications.

## Key Responsibilities
1. Review User Story for completeness
2. Create Design Document with:
   - Problem statement and business case
   - Functional requirements
   - Non-functional requirements
   - Proposed approach
   - Alternatives considered
   - Risk assessment
3. Define technical scope boundaries

## Key Outputs
- `WorkItems/<id>/Design/<id>-design-doc.md`
- `WorkItems/<id>/RoleDecisionNotes/<id>-program-manager.md`

## Transition Guidance
**Ready to transition to Quality Assurance when:**
- Design Document is complete
- All requirements are testable
- Business case is documented

**Next Role:** quality-assurance
