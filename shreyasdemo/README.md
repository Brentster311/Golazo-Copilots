# Tic-Tac-Toe (MVP)

Simple local two-player Tic-Tac-Toe GUI for Windows using Python stdlib `tkinter`.

## Run

```bash
python app.py
```

## Test

Run with unittest (always available):

```bash
python -m unittest discover -s tests -p "test_*.py"
```

If `pytest` is installed, this also works:

```bash
pytest
```
