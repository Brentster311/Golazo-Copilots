# BOB-001 — Program Manager Decision Notes

## Decisions
1. **Single file approach**: No need for project structure — one script does everything.
2. **Keyframe interpolation**: Simplest way to animate between poses smoothly.
3. **Sine-wave kite motion**: Natural-looking sway without physics simulation.
4. **Delta-time animation**: Frame-rate independent, smooth on any hardware.

## Open Questions
- None — scope is clear and self-contained.
